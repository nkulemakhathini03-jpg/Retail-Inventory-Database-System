# Retail Inventory Database System (RDBMS)

## Project Overview
This project demonstrates the design and execution of an enterprise relational database management system. Built to simulate a real-world retail inventory backend, it focuses on reducing data redundancy, establishing relational constraints, and optimizing data retrieval speeds.

## Core Technical Features
* **Database Normalization:** Built using 3NF (Third Normal Form) concepts to ensure high data integrity.
* **Relational Constraints:** Fully mapped utilizing explicit Primary Keys (PK) and Foreign Keys (FK) across master tables.
* **Advanced Querying:** Showcases optimized SQL scripts featuring Multi-table Inner/Left Joins, Subqueries, and Data Aggregation.

## Project Structure
* `schema.sql` - Structural database definition script (DDL).
* `queries.sql` - Advanced transactional and analytical data queries (DML).
